# Pulmuone Renewal — Design System

> **문서 목적**: 완료된 메인페이지의 실제 HTML/CSS를 기준으로 이후 서브페이지의 브랜드 정체성과 UI 규칙을 통일하기 위한 제작 기준입니다.
>
> **분석 범위**: `pulmuone/index.html`, `pulmuone/css/main.css`, `pulmuone/css/sub.css`, 공통 `css/default.css`, 그리고 현재 서브페이지 `company.html`, `food.html`, `news.html`의 공통 구조를 확인했습니다.
>
> **중요 원칙**: 이 문서는 디자인 가이드입니다. 메인페이지의 HTML/CSS/JS를 변경하지 않습니다. 아래 값은 저장소에서 확인한 구현값이며, 별도 표기가 없는 값은 새 브랜드 토큰으로 간주하지 않습니다.

## 1. Project Overview — 사이트 목적 및 디자인 방향

### 프로젝트 목적
- 풀무원의 브랜드 가치와 사업·활동 정보를 소개하는 브랜드 웹사이트 리뉴얼 프로젝트입니다.
- 메인페이지는 브랜드 소개 영역, 바른먹거리 콘텐츠, 캠페인, 뉴스룸 등으로 구성되어 방문자가 브랜드 메시지를 이해하고 관련 콘텐츠로 이동하도록 설계되어 있습니다.
- 서브페이지는 메인페이지의 시각 언어를 유지하면서 회사소개·바른먹거리·뉴스룸 정보를 더 깊게 전달하는 역할을 합니다.

### 디자인 방향
- **자연스럽고 건강한 인상**: 그린 계열을 핵심 강조색으로 사용하고, 흰색 배경과 짙은 회색 텍스트로 안정감을 줍니다.
- **콘텐츠 중심**: 큰 제목, 간결한 설명, 사진을 중심으로 정보를 전달합니다.
- **여백 중심의 편집형 레이아웃**: 섹션 사이에 넉넉한 세로 간격을 두고, 텍스트와 이미지의 역할을 구분합니다.
- **반복 UI의 일관성**: 헤더/GNB/푸터, 섹션 라벨, 카드, 링크의 모양과 상태 표현을 페이지마다 유지합니다.
- **반응형 정보 구조**: 화면이 좁아지면 열 수와 정렬을 바꾸되 콘텐츠의 읽는 순서와 중요도는 유지합니다.

### 페이지별 역할
| 페이지 | 역할 | 구현 파일 |
|---|---|---|
| 메인 | 브랜드 핵심 메시지와 주요 콘텐츠를 한눈에 소개 | `index.html` |
| 바른먹거리 | 지속가능 식생활, 식품 원칙 및 관련 콘텐츠 안내 | `food.html` |
| 뉴스룸 | 뉴스·ESG·멀티미디어 등 소식 전달 | `news.html` |
| 회사소개 | 기업 소개와 가치체계·연혁 등 정보 전달 | `company.html` |

## 2. Brand Identity — 브랜드 특성과 시각적 정체성

### 브랜드를 표현하는 키워드
- 바른먹거리와 건강한 식생활
- 사람과 지구의 건강한 내일
- 자연, 환경, 지속가능성
- 신뢰감 있는 기업 정보 전달

### 화면에서 확인되는 시각적 특징
1. **그린 포인트**: 섹션 영문 라벨, 현재 메뉴, 강조 링크 등에 그린을 사용합니다.
2. **화이트 중심 배경**: 콘텐츠를 돋보이게 하고 페이지가 무겁거나 복잡해 보이지 않도록 합니다.
3. **다크 그레이 텍스트**: 큰 제목과 본문에 사용해 선명한 정보 위계를 만듭니다.
4. **사진 중심 구성**: 식품·자연·사람·브랜드 활동을 보여주는 이미지를 주요 콘텐츠로 사용합니다.
5. **둥근 이미지 모서리**: 카드 이미지와 캠페인 이미지에서 주로 16px 라운드를 사용합니다.
6. **영문 섹션 라벨**: ABOUT PULMUONE, RIGHT FOOD, PULMUONE NEWSROOM처럼 섹션 주제를 먼저 인지하도록 돕습니다.
7. **큰 제목과 짧은 설명**: 제목으로 핵심 주제를 전달하고, 설명문으로 내용을 보충합니다.

### 서브페이지 적용
- 새로운 색상이나 장식 스타일을 추가하기보다 기존 그린·화이트·다크 그레이 조합을 우선 사용합니다.
- 페이지마다 다른 디자인 언어를 만들지 말고, 같은 제목 체계·컨테이너·카드 스타일을 사용합니다.
- 사진은 장식용으로만 배치하지 말고 주변 제목과 실제 콘텐츠의 의미가 연결되도록 선택합니다.

## 3. Design Principles — 디자인 설계 의도 및 핵심 원칙

1. **콘텐츠의 위계를 먼저 정합니다.** 페이지 제목 → 섹션 제목 → 설명 → 세부 콘텐츠 순서로 읽히게 구성합니다.
2. **큰 제목은 핵심 메시지에 사용합니다.** 모든 텍스트를 크게 만들지 말고, 가장 중요한 제목에만 강한 시각적 비중을 줍니다.
3. **여백으로 콘텐츠 그룹을 구분합니다.** 서로 다른 주제는 섹션 간 간격이나 얇은 구분선으로 분리합니다.
4. **이미지 비율을 통일합니다.** 같은 카드 목록 안에서는 이미지 비율과 모서리 반경을 맞춥니다.
5. **반복 컴포넌트는 재사용합니다.** Header, GNB, Footer, 섹션 제목, 카드, 링크를 페이지마다 새로 디자인하지 않습니다.
6. **상태를 색상과 움직임으로 명확하게 표현합니다.** Hover뿐 아니라 키보드 Focus와 현재 페이지 상태도 구분합니다.
7. **기존 기능을 과장하지 않습니다.** 실제 페이지 이동이나 언어 변경 기능이 구현되지 않았다면 동작하는 것처럼 표현하지 않습니다.
8. **메인페이지는 기준 원본입니다.** 서브페이지를 맞추기 위해 메인페이지의 기존 디자인이나 코드를 수정하지 않습니다.

## 4. Color System — 컬러 시스템

### 4-1. CSS 변수로 선언된 브랜드 컬러

아래 변수는 `pulmuone/css/main.css`의 `:root`에서 확인한 실제 선언값입니다. 서브페이지에서도 가능한 한 직접 색상 코드를 반복하지 말고 변수를 사용합니다.

| CSS 변수명 | 실제 코드 | 주요 사용 상황 |
|---|---|---|
| `--color-brand-green` | `#7bcc12` | 브랜드 포인트, 활성 페이지네이션, 포커스 강조 |
| `--color-brand-sub-green` | `#92c847` | 보조 그린. 필요한 경우에만 사용 |
| `--color-brand-dark-green` | `#2f6e23` | 현재 메뉴, 섹션 라벨, 강조 링크와 CTA |
| `--color-brand-dark-gray` | `#2d292a` | 주요 제목, 본문, 기본 텍스트 |
| `--color-brand-gray` | `#a0a4a8` | 보조 설명 및 낮은 우선순위의 텍스트 |
| `--color-brand-white` | `#ffffff` | 기본 페이지 배경과 밝은 UI 요소 |

### 4-2. CSS에 직접 사용된 보조 색상

다음 값은 실제 CSS에서 확인되는 색상입니다. 브랜드 컬러 변수와 구분해서 사용하고, 필요한 컴포넌트에만 적용합니다.

| 실제 코드 | 확인된 사용 맥락 |
|---|---|
| `#fff` | 헤더 및 흰색 배경 |
| `#f1f1f1` | 유틸리티 메뉴·탭 등 얇은 구분선 |
| `#f5f6f3` | 푸터 및 일부 콘텐츠 영역의 옅은 배경 |
| `#e5e8e2`, `#dfe3dc` | 푸터 경계선 등 저대비 구분선 |
| `#e8eddf` | 캠페인 카드의 기본 배경 |
| `rgba(0, 0, 0, 0.1)` | 뉴스룸 카드 테두리 |
| `rgba(47, 110, 35, .88)` | 바른먹거리 카드 Hover 오버레이 |

### 4-3. 컬러 적용 규칙
- 페이지 기본 배경은 `var(--color-brand-white)` 또는 실제 메인에서 쓰는 흰색을 우선합니다.
- 주요 제목·본문은 `var(--color-brand-dark-gray)`를 기본으로 합니다.
- 강조 라벨, 현재 GNB, 강조 링크는 `var(--color-brand-dark-green)`를 사용합니다.
- 밝은 그린 `--color-brand-green`은 강조가 필요한 상태에 제한적으로 사용합니다. 큰 면적의 배경에 무조건 적용하지 않습니다.
- `--color-brand-gray`는 보조 설명용입니다. 중요한 본문 전체를 이 색으로 처리해 가독성을 낮추지 않습니다.
- 위에 없는 색상을 새 브랜드 컬러인 것처럼 임의로 만들지 않습니다. 이미지 자체의 색상과 UI 컬러는 구분합니다.

## 5. Typography — 타이포그래피

### 5-1. 글꼴
- CSS 기본 폰트 변수: `--font-family-base: "Pretendard Variable", Pretendard, sans-serif`
- 기본 적용 방식: `font-family: var(--font-family-base)`
- HTML은 `../font/css/pretendardvariable.css`를 연결하고 있습니다.
- 저장소 파일 트리에서 이 상대경로가 가리키는 `font/css/pretendardvariable.css` 파일은 확인되지 않았습니다. 실제 배포에서 Pretendard가 로드되는지 개발자 도구의 Network/Computed 탭에서 확인해야 합니다. 폰트 파일이 로드되지 않으면 시스템의 대체 sans-serif가 표시될 수 있습니다.

### 5-2. 메인·서브페이지에서 확인되는 크기 체계

| 요소 / 상황 | 구현값 예시 | 사용 기준 |
|---|---|---|
| 유틸리티 메뉴 | 데스크톱 16px / 500, 작은 화면에서 12px·11px 규칙 존재 | 로그인·고객센터 등 보조 탐색 |
| GNB | 데스크톱 18px / 600 / line-height 1.2 | 주요 페이지 이동 |
| GNB 하위 메뉴 | 18px / 500 | 메뉴 상세 이동 |
| 섹션 영문 라벨 | 20px / 700 / line-height 1.4 | 섹션 주제 표시 |
| 메인 RIGHT FOOD 제목 | `clamp(48px, 5vw, 80px)` / 600 / 1.15 | 핵심 섹션 제목 |
| 메인 캠페인·뉴스룸 제목 | 대체로 `clamp(44px, 4.2vw, 75~80px)` / 600 | 섹션 대표 제목 |
| 서브페이지 H1 | `clamp(48px, 5vw, 80px)` / 600 / 1.15 | 페이지 대표 제목 |
| 서브페이지 H2 | `clamp(32px, 3vw, 48px)` / 600 / 1.25 | 본문 섹션 제목 |
| 본문 설명 | 주로 20px / 500~600 / 1.5~1.6 | 제목 보충 설명 |
| 서브 카드 제목 | `clamp(18px, 1.25vw, 20px)` / 600 / 1.4 | 카드 내용 제목 |
| 뉴스룸 카드 제목 | `clamp(18px, 1.25vw, 24px)` 규칙 및 후속 화면별 17~18px 규칙 존재 | 뉴스 요약 제목 |

> 메인 CSS에는 같은 선택자를 뒤에서 다시 덮어쓰는 규칙이 있습니다. 위 표는 코드에서 확인한 대표 규칙이며, 모든 요소에 동일하게 최종 적용된다는 뜻은 아닙니다. 실제 최종값은 브라우저 개발자 도구에서 확인합니다.

### 5-3. 타이포그래피 규칙
- 큰 제목은 고정 px보다 `clamp()`를 우선해 화면 너비에 따라 자연스럽게 줄어들게 합니다.
- 제목은 주로 600, 섹션 라벨·짧은 강조 문구는 700을 사용합니다.
- 본문은 500~600 범위에서 내용의 중요도에 맞춰 선택합니다.
- 한글 제목과 설명에는 `word-break: keep-all`을 사용해 단어 중간 줄바꿈을 줄입니다.
- 제목과 설명의 크기 차이를 유지해 정보 위계를 분명하게 합니다.
- 행간은 제목 1.15~1.25, 본문 1.4~1.6의 실제 사용 패턴을 참고하되 콘텐츠 길이에 맞게 조정합니다.

## 6. Layout & Spacing — 레이아웃 및 간격

### 6-1. 컨테이너 너비
| 영역 | 확인된 규칙 | 적용 상황 |
|---|---|---|
| Header 내부 | `width: min(calc(100% - 40px), 1720px)`, `max-width: 1720px` | 헤더 콘텐츠의 좌우 정렬 |
| 메인 섹션 inner | `max-width: 1720px` 규칙 | 메인 섹션 제목·카드 콘텐츠 정렬 |
| 서브페이지 inner | `width: min(1700px, calc(100% - 80px))` | 서브페이지 기본 콘텐츠 |
| 900px 이하 서브 inner | `width: calc(100% - 40px)` | 태블릿·모바일 좌우 여백 확보 |

- 메인에는 전체 폭을 사용하는 캠페인·비주얼 영역과 제한된 폭의 텍스트·카드 영역이 함께 있습니다.
- 모든 섹션을 무조건 같은 폭으로 만들지 말고, 배경이나 슬라이더는 넓게 쓰되 텍스트와 카드 목록은 inner 안에서 정렬합니다.
- 서브페이지 본문은 기본적으로 `.sub-inner`를 사용하고, Header/Footer의 폭과 시각적 중심을 맞춥니다.

### 6-2. 섹션 여백
- 데스크톱 주요 섹션에는 `110px` 전후의 상하 패딩을 사용하는 규칙이 있습니다.
- 서브페이지 `.sub-section` 기본 패딩도 `110px 0`입니다.
- 900px 이하에서는 주요 섹션 패딩이 대체로 72px로 줄어듭니다.
- 600px 이하 서브페이지는 섹션 패딩을 56px로 줄입니다.
- 메인 일부 섹션은 별도 규칙으로 72px 등을 사용하므로 모든 영역에 110px를 강제하지 않습니다.

### 6-3. Grid / Flex 사용
- **Flex**: Header의 로고·GNB·언어 선택, 유틸리티 메뉴, Footer 상단 링크 등 한 방향으로 정렬할 때 사용합니다.
- **Grid**: RIGHT FOOD 카드 3열, 뉴스룸 카드 3열, 서브 카드 목록, 텍스트·이미지 분할 레이아웃에 사용합니다.
- **2열 분할**: 서브페이지 `.sub-section--split .sub-inner`는 데스크톱에서 `1fr 1fr`와 80px 간격을 사용하고, 900px 이하에서 1열로 전환합니다.
- **3열 카드**: 메인 뉴스룸과 서브 카드 목록은 데스크톱에서 3열을 기본으로 합니다. 서브 카드 목록은 1024px 이하에서 2열, 600px 이하에서 1열로 바뀝니다.
- **이미지 비율**: 일반 카드 이미지는 `508 / 358`, 뉴스룸 이미지는 `509 / 300` 등 실제 컴포넌트 비율을 따릅니다. 서로 다른 유형의 이미지를 같은 비율로 억지로 맞추지 않습니다.

## 7. Components — 공통 UI 컴포넌트

### 7-1. Header
- 전체 영역은 `.site-header`입니다. 흰색 배경, 기본 텍스트 `var(--color-brand-dark-gray)`, `z-index: 20`을 사용합니다.
- `.header-inner`는 최대 1720px, 좌우 20px 계열의 여백을 두고 가운데 정렬합니다.
- `.utility-nav`는 로그인·고객센터·공지사항 등 보조 메뉴를 오른쪽으로 정렬하며 하단에 얇은 구분선을 둡니다.
- `.header-main`은 로고·GNB·언어 선택을 배치합니다. 기본 데스크톱 높이는 86px 규칙이며 반응형에서 줄어듭니다.
- `.brand-logo`는 이미지 로고를 사용합니다. 데스크톱 너비 210px, 1024px 이하에서 150px 규칙이 확인됩니다.
- 서브페이지에서도 같은 Header 구조와 클래스를 재사용합니다.

### 7-2. GNB / 하위 메뉴
- `.main-nav`는 가로형 Flex 메뉴이며 데스크톱 메뉴 간격은 57px 규칙입니다.
- 주요 메뉴는 18px / 600, 다크 그레이를 기본으로 합니다.
- 하위 메뉴 `.gnb-panel`은 흰색 배경의 가로 패널이며, 각 메뉴 그룹을 세로 목록으로 보여줍니다.
- 메뉴 패널은 기본적으로 숨겨져 있다가 마우스 Hover 또는 키보드 `:focus-within` 상태에서 표시되는 규칙이 있습니다.
- 현재 페이지는 `aria-current="page"`와 `var(--color-brand-dark-green)`로 구분합니다.
- 메뉴 링크는 공식 브랜드 사이트가 아니라 프로젝트 내부의 실제 페이지(예: `food.html`, `news.html`, `company.html`) 또는 해당 페이지 내 실제 ID로 연결합니다.

### 7-3. Language Switch
- `.language-switch`는 KR / EN 텍스트 버튼 형태이며, 현재 선택은 `.current` 클래스로 진한 그린을 적용합니다.
- JavaScript는 클릭된 버튼에 `.current`와 `aria-pressed`를 갱신합니다.
- 현재 확인한 스크립트는 선택 표시만 전환하며, 실제 페이지 콘텐츠를 번역하거나 영문 페이지로 이동시키는 기능은 확인되지 않았습니다. 서브페이지에서도 기능이 구현되지 않았다면 실제 언어 전환처럼 안내하지 않습니다.

### 7-4. Buttons / CTA / Links
- 주요 링크는 텍스트 중심으로 표현하고, 필요할 때 밑줄·하단 테두리·화살표를 사용합니다.
- RIGHT FOOD의 더보기 링크는 텍스트와 아이콘, 하단 테두리를 조합합니다.
- 캠페인 CTA는 얇은 테두리 버튼 형태이며 Hover 시 다크 그린 배경과 흰색 텍스트로 전환되는 규칙이 있습니다.
- 언어 선택 버튼은 별도의 박스형 버튼이 아니라 텍스트형입니다.
- 새 CTA는 페이지의 핵심 행동을 분명히 보여주고, 한 영역에 중요도가 같은 버튼을 과도하게 나열하지 않습니다.

### 7-5. Cards
**RIGHT FOOD 카드**
- `.right-food-card`는 이미지 기반 카드입니다.
- 기본 이미지 비율은 초기 규칙에서 `508 / 358`, 최종 화면 구성에는 카드 전체를 세로형으로 채우는 규칙도 있습니다.
- Hover/Focus 시 그린 계열 오버레이가 나타나고 제목·설명이 아래에서 올라오며 표시됩니다.
- 카드 전체를 클릭할 수 있는 구조이므로 키보드 Focus도 동일한 내용을 확인할 수 있어야 합니다.

**Campaign 카드**
- `.campaign-vehicle-style__card`는 큰 이미지 카드이며, 기본 상태는 낮은 불투명도와 축소된 크기, 활성 상태는 원래 크기와 높은 불투명도로 표현합니다.
- 이미지 위에 어두운 그라데이션과 흰색 텍스트를 겹쳐 이미지 위에서도 제목이 읽히게 합니다.
- 카드 모서리는 16px 규칙을 사용합니다.

**Newsroom 카드**
- `.newsroom-card`는 이미지와 제목을 하나의 링크 콘텐츠로 묶습니다.
- 이미지 비율은 `509 / 300` 규칙이며 제목은 카드 내부 여백을 둡니다.
- 현재 최종 규칙에서 카드 테두리는 `1px solid rgba(0, 0, 0, 0.1)`, 제목 패딩은 `0 16px 16px 16px`입니다.
- Hover/Focus 시 제목 밑줄 또는 텍스트 색으로 상호작용을 알려줍니다.

### 7-6. Footer
- `.pulmuone-footer`는 옅은 회색·그린 계열 배경(`#f5f6f3`)과 상단 경계선으로 본문과 구분됩니다.
- 상단은 브랜드 로고와 푸터 링크를 양쪽으로 배치하고, 하단은 브랜드 설명·포트폴리오 안내·저작권 정보를 배치합니다.
- 링크는 회사소개·뉴스룸·고객기쁨센터·개인정보처리방침·이용약관 역할로 구성됩니다.
- 개인정보처리방침은 `.is-emphasis` 클래스로 강조합니다.
- 서브페이지에도 동일한 구조를 재사용하되 링크는 프로젝트 내부에서 실제로 구현한 페이지나 앵커로 연결합니다.

### 7-7. 서브페이지 전용 공통 패턴
`pulmuone/css/sub.css`에 이미 정의된 패턴을 우선 재사용합니다.
- `.sub-visual`: 페이지 상단 제목 영역. 영문 라벨, H1, 설명문으로 구성합니다.
- `.sub-tabs`: 페이지 내부 섹션 바로가기. 상·하단 얇은 경계선과 텍스트 링크를 사용합니다.
- `.sub-section`: 본문 콘텐츠 그룹. 기본 상하 패딩 110px이며 다음 섹션과 얇은 구분선을 둘 수 있습니다.
- `.sub-section--split`: 텍스트와 이미지를 2열로 배치하는 패턴입니다.
- `.sub-cards` / `.sub-card`: 반복 콘텐츠 카드 목록입니다.
- `.sub-logo`: CI 등 로고를 보여주는 박스형 영역입니다.

## 8. Interaction — Hover, Focus, Active, Transition

### Hover
- GNB 하위 패널은 메뉴 영역에 Hover하면 나타납니다.
- GNB 하위 링크는 Hover 시 다크 그린으로 바뀝니다.
- 서브 탭 링크는 Hover 시 `var(--color-brand-dark-green)`으로 바뀝니다.
- 뉴스룸 카드 제목은 Hover 시 밑줄 또는 강조 색으로 상태를 표현합니다.
- RIGHT FOOD 카드는 Hover 시 그린 오버레이와 제목·설명이 나타납니다.
- 캠페인 카드는 Hover 시 이미지가 확대되고 보조 화살표가 나타나는 규칙이 있습니다.

### Focus
- 공통 `css/default.css`는 기본 `:focus` 외곽선을 정리하고 `:focus-visible`에 `2px solid currentColor`, `2px offset`을 적용합니다.
- 언어 버튼과 카드 등 일부 컴포넌트는 브랜드 그린 외곽선과 3px offset을 별도로 사용합니다.
- 마우스 Hover만으로 정보를 제공하지 말고, 키보드로 접근했을 때도 핵심 정보와 링크 상태가 확인되어야 합니다.
- Focus 표시를 제거하거나 배경색만 바꾸는 것으로 대체하지 않습니다.

### Active / Selected
- 현재 페이지 GNB는 `aria-current="page"`로 표시합니다.
- 언어 버튼 선택은 `.current` 및 `aria-pressed`로 표시합니다.
- Swiper 활성 페이지네이션은 브랜드 그린, 비활성 상태는 밝은 색 계열을 사용합니다.
- 캠페인 슬라이드는 활성 카드에 크기·불투명도 차이를 적용합니다.

### Transition / Motion
- CSS에서 확인되는 전환 시간은 컴포넌트별로 다릅니다. 예: GNB 약 0.25초, CTA 약 0.25초, 캠페인 카드 약 0.45~0.65초, 이미지 확대 약 0.7초 등.
- ABOUT 영역에는 스크롤 진행에 따라 제목 색상이 채워지는 효과가 있습니다.
- 메인페이지의 카드·슬라이더 효과를 서브페이지에 그대로 복제하기보다 콘텐츠 성격에 맞는 최소한의 움직임만 사용합니다.
- `prefers-reduced-motion: reduce`를 고려해 애니메이션·전환을 줄이거나 정적으로 표시합니다.

## 9. Responsive Rules — 반응형 디자인 기준

### 실제 CSS에서 확인되는 주요 분기점

| 미디어 조건 | 실제 적용 방향 |
|---|---|
| `max-width: 1200px` | ABOUT 콘텐츠의 열 비율·간격·좌우 패딩 조정 |
| `max-width: 1024px` | 헤더 로고·메뉴 크기 조정, 이미지 전환 및 서브 카드 2열 규칙 |
| `max-width: 900px` | 메인 ABOUT 및 일부 카드 레이아웃 1열 전환, 서브페이지 split 1열 전환, 섹션 여백 축소 |
| `max-width: 600px` | 헤더 메뉴 재배치, 서브 카드 1열, 탭 간격 축소 |
| `max-width: 560px` | 캠페인 카드·제목·간격 등 작은 화면 전용 조정 |

### 화면 크기별 제작 원칙
- **데스크톱**: 큰 제목과 넓은 콘텐츠 폭을 사용하고, 카드 목록은 3열을 기본으로 합니다.
- **태블릿**: 카드 수와 메뉴 간격을 줄이고, 이미지와 텍스트가 지나치게 좁아지면 1열 전환을 고려합니다.
- **모바일**: 콘텐츠를 세로로 쌓고 좌우 20px 안팎의 여백을 유지합니다. 제목과 설명이 화면 밖으로 넘치지 않도록 합니다.
- 메인 히어로는 화면 크기에 따라 PC/모바일 이미지를 전환하는 `.pc`, `.mo` 규칙이 있습니다.
- 이미지에는 컴포넌트 목적에 따라 `object-fit: cover` 또는 `contain`을 선택합니다. 로고는 잘리지 않도록 `contain`을 우선합니다.
- 브레이크포인트 숫자만 복사하지 말고 실제 기기 폭에서 GNB, 카드, 이미지, 문단 줄바꿈을 확인합니다.

## 10. Do & Don't — 반드시 지킬 규칙과 금기사항

### DO
- [ ] 색상은 먼저 `:root`의 `--color-brand-*` 변수를 사용합니다.
- [ ] 폰트는 `var(--font-family-base)`를 사용합니다.
- [ ] 메인과 같은 Header/GNB/Footer 구조와 클래스 역할을 재사용합니다.
- [ ] 페이지 제목·섹션 제목·설명·카드 제목의 위계를 유지합니다.
- [ ] 동일한 카드 유형끼리는 이미지 비율·모서리·간격을 통일합니다.
- [ ] `sub.css`에 이미 정의된 `.sub-visual`, `.sub-section`, `.sub-cards` 패턴을 우선 사용합니다.
- [ ] Hover, Focus-visible, Active/Current 상태를 함께 설계합니다.
- [ ] 키보드 탐색과 `prefers-reduced-motion` 설정을 확인합니다.
- [ ] 내부 이동은 실제 구현된 프로젝트 페이지와 ID로 연결합니다.
- [ ] CSS 수정 전 기존 선택자와 미디어쿼리의 중복 선언 및 우선순위를 확인합니다.

### DON'T
- [ ] 기존 변수에 없는 색상을 임의로 브랜드 컬러라고 정의하지 않습니다.
- [ ] 근거 없이 모든 섹션에 같은 패딩·폰트 크기·카드 비율을 강제하지 않습니다.
- [ ] 서브페이지 작업을 이유로 메인페이지의 디자인·HTML·CSS·JS를 변경하지 않습니다.
- [ ] 공식 풀무원 사이트나 공식 뉴스룸 URL을 새 서브페이지 링크 대상으로 사용하지 않습니다.
- [ ] 목적 없는 그림자·그라데이션·아이콘·모션을 추가하지 않습니다.
- [ ] Hover만 구현하고 키보드 Focus 상태를 생략하지 않습니다.
- [ ] 모바일에서 데스크톱 레이아웃을 그대로 축소해 글자와 카드가 겹치게 만들지 않습니다.
- [ ] 실제 번역·로그인·고객센터 기능이 없는 상태에서 동작하는 것처럼 표현하지 않습니다.

### 링크 연결 시 주의할 현재 상태
- 메인페이지의 GNB는 `food.html`, `news.html`, `company.html` 등 프로젝트 내부 페이지로 연결됩니다.
- 메인페이지 뉴스룸 카드 일부에는 현재 공식 뉴스룸의 외부 URL이 들어 있습니다. **메인페이지의 기존 링크는 이 문서 작업에서 변경하지 않았습니다.** 다만 새 서브페이지를 만들 때는 요청 기준에 따라 공식 브랜드 사이트로 연결하지 말고, 프로젝트 내부 상세 페이지 또는 실제로 구현한 내부 앵커를 사용합니다.
- 푸터 일부 링크는 `#company`, `#customer`, `#privacy`, `#terms` 같은 앵커 형식입니다. 각 페이지에 해당 ID가 실제 존재하는지 확인한 뒤 사용합니다. 대상이 없으면 임의로 연결하지 말고 내부 페이지를 제작하거나 링크 기능을 보류합니다.

## Implementation Reference — 파일 및 확인 사항

| 구분 | 경로 | 역할 |
|---|---|---|
| 메인 HTML | `pulmuone/index.html` | 메인페이지 구조와 스크립트 |
| 메인/공통 CSS | `pulmuone/css/main.css` | 메인 스타일, 브랜드 변수, 공통 Header/Footer |
| 서브페이지 CSS | `pulmuone/css/sub.css` | 서브페이지 본문 공통 패턴 |
| 공통 초기화 | `css/default.css` | 기본 요소 초기화, Focus, 모션 감소 설정 |
| 바른먹거리 | `pulmuone/food.html` | 서브페이지 예시 |
| 뉴스룸 | `pulmuone/news.html` | 서브페이지 예시 |
| 회사소개 | `pulmuone/company.html` | 서브페이지 예시 |

### 구현 전 확인할 사항
1. CSS에 동일한 선택자가 여러 번 등장하는 경우가 있으므로 파일의 첫 선언만 보고 최종 스타일이라고 판단하지 않습니다.
2. `!important`가 이미 사용된 영역은 새 규칙을 무작정 추가하기보다 기존 규칙의 적용 범위와 선언 순서를 먼저 확인합니다.
3. Pretendard 폰트 CSS 링크가 저장소의 실제 파일 경로와 일치하는지 확인하고, 폰트 로딩 실패 시 대체 폰트가 적용되는지 테스트합니다.
4. 새 페이지의 모든 링크가 실제 내부 목적지로 이동하는지 확인합니다.
5. 이 문서의 수치는 저장소에서 확인한 현재 구현 기준입니다. 향후 메인페이지가 변경되면 Design.md도 다시 검토해야 합니다.
