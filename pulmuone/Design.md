# Pulmuone Website Renewal — Design System

> 이 문서는 `pulmuone/index.html`과 `pulmuone/css/main.css`, 공통 초기화 파일 `css/default.css`에 구현된 메인페이지를 기준으로 정리한 서브페이지 제작 가이드입니다.
>
> **적용 원칙:** 기존 메인페이지의 디자인을 변경하지 않습니다. 아래 규칙은 새 서브페이지를 제작할 때 재사용하며, 메인페이지에 없는 색상·수치·컴포넌트는 임의로 브랜드 규칙인 것처럼 추가하지 않습니다.

---

## 1. Project Overview — 사이트 목적 및 디자인 방향

### 사이트 목적
- 풀무원의 브랜드 가치인 **바른먹거리**와 사람·지구의 건강한 내일이라는 메시지를 소개하는 브랜드 웹사이트 리뉴얼 프로젝트입니다.
- 메인페이지는 브랜드 소개(ABOUT PULMUONE), 바른먹거리(RIGHT FOOD), 캠페인, 뉴스룸으로 콘텐츠를 구성합니다.
- 사용자가 브랜드의 가치와 활동을 이해한 뒤 관련 콘텐츠를 더 살펴보도록 안내합니다.

### 디자인 방향
- 자연·건강·지속가능성을 연상시키는 그린 계열을 핵심 브랜드 컬러로 사용합니다.
- 넓은 이미지와 큰 제목을 활용해 브랜드 메시지를 명확하게 전달합니다.
- 섹션마다 충분한 여백을 두고, 텍스트와 이미지의 역할을 구분합니다.
- 뉴스룸과 캠페인 등 정보성 콘텐츠는 카드와 이미지 중심으로 구성합니다.
- 전체적으로 밝은 배경과 짙은 본문색을 사용해 읽기 쉬운 화면을 만듭니다.

**서브페이지 적용:** 메인페이지의 색상·글꼴·헤더·푸터·링크 표현을 이어가되, 페이지 목적에 맞춰 콘텐츠 구조만 조정합니다.

## 2. Brand Identity — 브랜드 특성과 시각적 정체성

### 핵심 키워드
- 바른먹거리
- 건강한 식생활
- 자연과 환경
- 지속가능성
- 신뢰와 정보 전달

### 시각적 표현
- **그린:** 브랜드와 바른먹거리의 핵심 이미지를 표현합니다.
- **화이트:** 콘텐츠가 답답해 보이지 않도록 배경과 여백에 사용합니다.
- **다크 그레이:** 제목과 본문에 사용해 안정적인 가독성을 확보합니다.
- **사진 중심 콘텐츠:** 식품·자연·사람과 관련된 이미지를 큰 비중으로 사용합니다.
- **둥근 이미지 모서리:** RIGHT FOOD 카드 등 이미지 콘텐츠에서 부드러운 인상을 줍니다.
- **영문 섹션 라벨:** ABOUT PULMUONE, RIGHT FOOD, PULMONE NEWSROOM처럼 섹션의 성격을 짧게 표시합니다.

## 3. Design Principles — 디자인 설계 의도 및 핵심 원칙

1. **브랜드 메시지를 먼저 전달합니다.** 페이지 첫 화면과 섹션 제목에서 해당 콘텐츠의 주제를 빠르게 파악할 수 있어야 합니다.
2. **큰 제목과 짧은 설명을 조합합니다.** 제목은 핵심 메시지, 설명은 맥락을 보충하는 역할을 합니다.
3. **이미지는 콘텐츠를 설명해야 합니다.** 장식 목적만으로 이미지를 넣지 말고 주변 제목·설명과 의미가 연결되도록 합니다.
4. **섹션 간 여백으로 내용을 구분합니다.** 서로 다른 주제가 한 덩어리로 보이지 않도록 섹션 패딩과 내부 간격을 조절합니다.
5. **반복 UI는 같은 규칙을 사용합니다.** 링크, 카드, 섹션 라벨, 버튼은 페이지마다 모양과 동작이 달라지지 않도록 합니다.
6. **반응형에서도 정보 순서를 유지합니다.** 화면이 좁아지면 다단 레이아웃을 한 열로 바꾸되 제목·설명·주요 행동의 순서는 유지합니다.
7. **접근 가능한 인터랙션을 유지합니다.** 마우스뿐 아니라 키보드 포커스 상태도 확인합니다.

## 4. Color System — 컬러 시스템

아래 6개 값은 `main.css :root`에 CSS 변수로 실제 선언되어 있습니다. 새 페이지에서는 가능한 한 변수명을 사용합니다.

| CSS 변수 | 실제 값 | 사용 목적 |
|---|---|---|
| `--color-brand-green` | `#7bcc12` | 핵심 브랜드 그린, 활성 페이지네이션 및 포커스 강조 |
| `--color-brand-sub-green` | `#92c847` | 보조 브랜드 그린 |
| `--color-brand-dark-green` | `#2f6e23` | 강조 텍스트, 브랜드 링크, 활성 언어 |
| `--color-brand-dark-gray` | `#2d292a` | 기본 제목·본문 및 헤더 텍스트 |
| `--color-brand-gray` | `#a0a4a8` | 보조 설명, 비활성 언어 등 보조 텍스트 |
| `--color-brand-white` | `#ffffff` | 기본 배경, 이미지 슬라이더의 비활성 페이지네이션 |

### 실제 스타일에 직접 사용된 보조 색상
다음 값은 CSS에서 직접 사용된 색상이며, 별도 CSS 변수로 선언된 값은 아닙니다.

- `#fff`: 헤더와 주요 섹션의 흰색 배경
- `#f1f1f1`: 유틸리티 메뉴 하단 구분선
- `#c8c8c8`: 스크롤에 따라 채워지는 ABOUT 제목의 미완료 텍스트
- `#292526`: ABOUT 제목의 스크롤 채움 완료 색상
- `#e6f0d9`, `#c4d9a5`, `#83a65b`: 소개 비주얼의 자연 계열 그라데이션
- `#e8eddf`: 캠페인 카드의 기본 배경색

### 컬러 사용 규칙
- 기본 배경은 흰색을 우선 사용합니다.
- 제목과 주요 본문은 `var(--color-brand-dark-gray)`를 사용합니다.
- 브랜드 의미를 강조하는 짧은 라벨이나 주요 링크에는 `var(--color-brand-dark-green)`를 사용합니다.
- 밝은 그린(`--color-brand-green`)은 활성 상태나 강조가 필요한 부분에 제한적으로 사용합니다.
- 회색(`--color-brand-gray`)은 본문보다 중요도가 낮은 설명에 사용합니다.
- 위에 없는 새 브랜드 컬러를 임의로 만들지 않습니다. 사진·일러스트 내부 색상은 UI 컬러 토큰과 구분합니다.

## 5. Typography — 타이포그래피

### 글꼴
- `main.css`에 선언된 기본 글꼴 변수: `--font-family-base: "Pretendard Variable", Pretendard, sans-serif`
- 본문은 `font-family: var(--font-family-base)`를 사용합니다.
- HTML은 `../font/css/pretendardvariable.css`를 연결하고 있습니다. 이 경로의 폰트 파일은 현재 확인한 저장소 파일 목록에서 확인되지 않았으므로, 실제 배포 시 폰트가 정상 로드되는지 점검해야 합니다.

### 메인페이지에서 확인되는 크기·굵기 예시
| 요소 / 상황 | 구현된 값 | 적용 의도 |
|---|---|---|
| 유틸리티 링크(데스크톱) | 16px / 500 | 보조 메뉴 |
| 주요 GNB | 18px / 600 / line-height 1.2 | 주요 탐색 메뉴 |
| 영문 섹션 라벨 | 20px / 700 / line-height 1.4 (일부 섹션) | 섹션 주제 표시 |
| ABOUT 제목 | `clamp(36px, 4.2vw, 80px)` / 600 / 1.35 | 브랜드 핵심 메시지 |
| RIGHT FOOD 제목 | `clamp(48px, 5vw, 80px)` / 600 / 1.15 | 섹션 대표 제목 |
| 본문 설명 | 20px / 600 / line-height 1.5~1.6 (섹션별 상이) | 제목 보충 설명 |
| 카드 제목 | 반응형 크기 사용, 캠페인 제목은 `clamp(28px, 2.1vw, 40px)` / 1.2 | 이미지 위 콘텐츠 제목 |
| 뉴스 카드 제목 | `clamp(18px, 1.25vw, 20px)` | 여러 뉴스 항목의 요약 |

### 타이포그래피 규칙
- 큰 제목은 고정 크기만 사용하지 않고 `clamp()`로 화면 너비에 맞춰 조절합니다.
- 제목은 대체로 600 굵기, 섹션 라벨과 강조 텍스트는 700 굵기를 사용합니다.
- 한글 제목은 `word-break: keep-all`을 기본으로 하여 단어 중간에서 줄바꿈되는 현상을 줄입니다.
- 제목은 짧고 명확하게, 설명문은 제목보다 작은 크기와 낮은 강조도로 구성합니다.
- 같은 역할의 제목은 서브페이지에서도 동일한 크기 체계를 사용하고, 임의의 굵기·행간을 반복해서 추가하지 않습니다.

## 6. Layout & Spacing — 레이아웃 및 간격

### 컨테이너
- 메인 헤더 내부: 데스크톱 `width: min(100% - 40px, 1720px)` 계열, 가운데 정렬.
- 주요 섹션 내부: `width: min(100%, 1720px)` 또는 `width: min(1700px, calc(100% - 80px))` 등 섹션별 구현값을 사용합니다.
- 콘텐츠가 넓게 펼쳐지는 메인 비주얼과 캠페인 영역은 화면 전체 너비를 사용합니다.
- 섹션 내부의 제목·카드 영역은 별도 inner 컨테이너로 묶어 정렬합니다.

### 여백
- 데스크톱 섹션 패딩은 110px 전후의 큰 여백을 사용하는 영역이 있으며, 일부 섹션은 72px 또는 42px 등 콘텐츠 특성에 맞게 다르게 설정되어 있습니다.
- 태블릿·모바일에서는 주요 섹션의 세로 패딩을 72px, 56px, 44px 등으로 줄입니다.
- 카드 그리드는 데스크톱에서 40px 간격을 사용하는 영역이 있고, 화면이 좁아지면 간격을 줄이거나 한 열로 변경합니다.
- 숫자는 모든 섹션에 일괄 적용하는 고정 토큰이 아니라 현재 메인페이지의 섹션별 구현값입니다. 새 페이지에서는 콘텐츠 밀도에 맞춰 조정하되 메인페이지와 시각적 리듬을 맞춥니다.

### 레이아웃 패턴
- **Flex:** 헤더의 로고·GNB·언어 선택, 유틸리티 메뉴, 버튼 내부 정렬 등 한 방향 정렬에 사용합니다.
- **Grid:** ABOUT의 텍스트·비주얼 2열 구성, RIGHT FOOD 카드 3열 구성, 뉴스룸 카드 목록에 사용합니다.
- **전체 폭 이미지:** 메인 히어로와 캠페인 슬라이더처럼 이미지가 화면의 시각적 중심인 영역에 사용합니다.
- **카드 레이아웃:** 반복되는 콘텐츠를 동일한 너비·이미지 비율·제목 간격으로 정렬합니다.

## 7. Components — 공통 UI 컴포넌트

### Header
- `.site-header`가 전체 헤더이며, 흰색 배경과 높은 레이어 순서(`z-index: 20`)를 사용합니다.
- `.utility-nav`: 로그인·고객센터·공지사항 보조 링크. 오른쪽 정렬, 하단 얇은 구분선.
- `.header-main`: 로고, 주요 메뉴, 언어 선택을 가로로 배치합니다.
- `.brand-logo`: 이미지 로고를 사용하며 데스크톱 너비 210px, 1024px 이하에서 150px로 조정됩니다.
- `.main-nav`: 바른먹거리·뉴스룸·회사소개 메뉴. 데스크톱 중앙 정렬.
- `.language-switch` / `.language-button`: KR·EN 버튼. 선택된 항목은 `.current` 클래스로 진한 그린을 적용하고 `aria-pressed` 상태를 갱신합니다.

**서브페이지 규칙:** 헤더의 HTML 구조와 클래스 역할을 재사용합니다. 메뉴 링크는 기존 브랜드 공식 사이트로 연결하지 말고, 실제 구현된 서브페이지 경로 또는 해당 페이지 내 앵커로 연결합니다. 아직 페이지가 없는 메뉴는 임의의 외부 주소를 넣지 않습니다.

### GNB / Links
- 주요 메뉴는 텍스트 중심으로 구성하며 아이콘을 불필요하게 추가하지 않습니다.
- 기본 링크는 주변 텍스트와 같은 계열의 색상을 사용하고, 브랜드 강조가 필요한 링크는 다크 그린을 사용합니다.
- 현재 페이지나 선택 상태는 색상·클래스 등 명확한 상태로 구분합니다.
- 외부 브랜드 사이트 URL을 새로 연결하지 않습니다. 서브페이지 간 이동은 프로젝트 내부 상대경로를 사용합니다.

### Buttons / CTA
- `.language-button`은 테두리와 배경을 제거한 텍스트형 버튼입니다.
- RIGHT FOOD의 더보기 링크는 텍스트와 화살표 아이콘, 하단 테두리로 구성됩니다.
- 캠페인 상세 링크는 얇은 테두리의 버튼 형태이며, hover 시 다크 그린 배경과 흰색 텍스트로 바뀝니다.
- CTA는 한 섹션에서 가장 중요한 다음 행동을 한 가지 중심으로 제시합니다.

### Cards
- `.right-food-card`: 이미지와 짧은 설명을 세로로 배치합니다. 이미지는 `aspect-ratio: 508 / 358`, `border-radius: 16px`를 사용합니다.
- `.campaign-vehicle-style__card`: 큰 배경 이미지 위에 어두운 그라데이션과 흰색 텍스트를 겹쳐 표시합니다. 활성 슬라이드는 크기와 불투명도로 강조합니다.
- `.newsroom-card`: 뉴스 이미지와 제목을 링크로 묶고, 제목은 hover/focus 시 밑줄로 상태를 표시합니다.

### Footer
- `.pulmuone-footer` 안에 브랜드 로고, 푸터 링크, 안내 문구, 저작권 문구를 배치합니다.
- 푸터 메뉴는 회사소개·뉴스룸·고객기쁨센터·개인정보처리방침·이용약관 역할로 구성되어 있습니다.
- 개인정보처리방침은 `.is-emphasis` 클래스로 강조합니다.
- 서브페이지에서도 동일한 푸터 구조를 재사용하되, 모든 링크는 프로젝트 내부 페이지 또는 실제로 제작된 앵커로 연결합니다.

## 8. Interaction — 인터랙션 상태

### Hover
- 뉴스룸 카드: 카드 제목에 밑줄을 표시하고 밑줄과 텍스트 사이 간격은 `text-underline-offset: 4px`로 둡니다.
- 캠페인 상세 CTA: 배경을 `#2f6e23`, 글자를 흰색으로 바꾸고 테두리도 같은 그린으로 변경합니다.
- 캠페인 카드 이미지: 확대 효과를 사용합니다. 현재 CSS에는 이미지 확대 전환과 카드 활성 상태의 크기·불투명도 전환이 정의되어 있습니다.

### Focus
- 언어 버튼은 `:focus-visible`에서 2px 브랜드 그린 외곽선과 3px offset을 표시합니다.
- 뉴스룸 제목은 링크에 키보드 포커스가 들어오면 hover와 동일하게 밑줄을 표시합니다.
- 공통 `default.css`는 `:focus` 기본 외곽선을 제거하고 `:focus-visible`에 2px `currentColor`, 2px offset을 적용합니다. 컴포넌트별 포커스 스타일이 있으면 해당 스타일이 우선합니다.
- 포커스 표시를 없애지 말고 키보드로 현재 위치를 확인할 수 있게 합니다.

### Active / Selected
- 언어 선택은 `.current` 클래스와 `aria-pressed` 값으로 표시합니다.
- Swiper 활성 페이지네이션은 브랜드 그린, 비활성 페이지네이션은 흰색 계열로 표시합니다.
- 캠페인 Swiper는 활성 슬라이드에 더 높은 불투명도와 큰 크기를 적용합니다.

### Transition / Motion
- 페이지네이션은 약 0.2초, CTA는 약 0.25초, 캠페인 이미지·슬라이드는 약 0.75초~1.2초 전환을 사용합니다.
- ABOUT 제목은 스크롤 진행에 따라 회색에서 짙은 색으로 채워지는 효과를 사용합니다.
- `prefers-reduced-motion: reduce` 설정에서는 애니메이션과 전환을 최소화하고 ABOUT 텍스트 채움 효과를 정적인 텍스트로 표시합니다.
- 새 인터랙션은 사용자의 행동 결과가 명확해야 하며, 장식 효과가 콘텐츠 읽기를 방해하지 않도록 합니다.

## 9. Responsive Rules — 반응형 기준

메인 CSS에서 실제 확인되는 주요 분기점은 다음과 같습니다.

| 미디어 조건 | 적용 기준 |
|---|---|
| `max-width: 1200px` | 일부 콘텐츠 컨테이너·간격 조정 |
| `max-width: 1024px` | PC/모바일 히어로 이미지 전환, 헤더 높이·로고·메뉴 크기 조정 |
| `max-width: 900px` | ABOUT·RIGHT FOOD 등 주요 2열/3열 레이아웃을 한 열로 전환 |
| `max-width: 600px` | 헤더 메뉴를 다음 줄로 배치하고 모바일 여백 조정 |
| `max-width: 560px` | 캠페인 카드·제목·간격 등 작은 화면 전용 조정 |

### 적용 규칙
- 데스크톱 히어로는 670px 높이로 설정된 최종 규칙이 있으며, 900px 이하에서는 `100dvh`를 사용합니다.
- 1024px 이하에서는 `.pc` 이미지를 숨기고 `.mo` 이미지를 표시합니다.
- 900px 이하에서는 ABOUT 콘텐츠를 1열로 전환하고 RIGHT FOOD 카드도 1열로 쌓습니다.
- 600px 이하에서는 헤더의 GNB를 별도 행으로 내려 메뉴가 겹치지 않도록 합니다.
- 560px 이하에서는 캠페인 제목·카드 높이·카드 내부 여백을 추가로 줄입니다.
- 이미지에는 `object-fit: cover`를 사용해 정해진 영역을 채우며, 이미지의 중요한 피사체가 잘리지 않는지 별도로 확인합니다.
- 반응형은 단순히 크기만 줄이는 것이 아니라 콘텐츠 순서, 정렬, 열 수를 화면에 맞게 변경합니다.

## 10. Do & Don't — 반드시 지킬 규칙과 금기사항

### DO
- [ ] 색상은 우선 `:root`의 브랜드 CSS 변수를 사용합니다.
- [ ] 글꼴은 `var(--font-family-base)`를 사용합니다.
- [ ] 헤더·GNB·푸터의 구조와 클래스 역할을 공통으로 유지합니다.
- [ ] 섹션 제목, 보조 라벨, 설명문의 위계를 유지합니다.
- [ ] 이미지 비율과 카드 간격을 같은 유형의 컴포넌트끼리 일관되게 적용합니다.
- [ ] 1200 / 1024 / 900 / 600 / 560px 분기점을 우선 참고하고 실제 화면에서 검수합니다.
- [ ] hover뿐 아니라 focus-visible과 active 상태도 구현합니다.
- [ ] 키보드 탐색과 모션 감소 설정을 확인합니다.
- [ ] 링크는 프로젝트 내부의 실제 페이지나 앵커로 연결합니다.

### DON'T
- [ ] 기존 CSS 변수에 없는 색상을 브랜드 컬러인 것처럼 임의 지정하지 않습니다.
- [ ] 근거 없이 모든 섹션에 동일한 패딩·간격·폰트 크기를 강제하지 않습니다.
- [ ] 메인페이지의 디자인이나 기존 CSS를 서브페이지 작업 과정에서 변경하지 않습니다.
- [ ] 기존 브랜드 공식 사이트로 연결되는 링크를 새로 만들지 않습니다.
- [ ] 목적 없는 장식용 그림자·그라데이션·아이콘을 추가하지 않습니다.
- [ ] hover 효과만 제공하고 키보드 focus 상태를 생략하지 않습니다.
- [ ] 모바일에서 데스크톱 레이아웃을 그대로 축소해 글자·버튼·카드가 겹치게 만들지 않습니다.
- [ ] 구현되지 않은 메뉴·언어 전환·기능이 실제 동작하는 것처럼 표시하지 않습니다.
